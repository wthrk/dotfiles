# AGENTS_ja.md

## 対象範囲

このファイルは `docs/` 配下のすべてに適用する。

## 翻訳同期

- `AGENTS_ja.md` は `AGENTS.md` と意味的に一致させる。
- `AGENTS.md` を編集する場合は、同一変更で `AGENTS_ja.md` も更新する。
- レビュー時に両文書の意味一致を確認する。

## 重要ルール

- `docs/` を恒久的なリポジトリ規則の正本として維持する。
- 規範文を文書間で重複させない。
- 責務が混ざり始めたら分割する。
- README は入口と導線だけに保つ。
- 他文書から参照される文書を変更した場合は、被参照が正しいファイルと見出しを指すことを確認する。

## 必須参照

- `docs/` 配下を編集する前に、[docs-governance.md](./docs-governance.md) を必ず読む。
- 変更がタスク規則またはタスク構造に触れる場合は、[task-governance/README.md](./task-governance/README.md) を必ず読む。
- 削除済みの task ledger、work item、review artifact、confirmation、issue progress、current-cycle 記録への参照を追加しない。
