# tasks / repo-governance

このディレクトリは、リポジトリ全体に関わるガバナンス文書・運用文書の台帳、作業定義、証跡を配置する。

全体入口は [../tasks.md](../tasks.md) であり、この README は repo-governance 領域確定後に読む領域内入口である。

## 配下の項目

- [tasks.md](tasks.md#repo-global-ガバナンス文書整合タスク): repo-governance 領域内の補助台帳/履歴。
- [work-items/README.md](work-items/README.md#repo-governance-work-items): 各作業項目の作業定義。
- [review-artifacts/README.md](review-artifacts/README.md#review-artifacts): 確認証跡とレビュー記録の配置先。

## 参照順

1. 全体運用は [../../task-governance/workflow.md](../../task-governance/workflow.md#タスク運用ワークフロー) を参照する。
2. active work item は [../tasks.md](../tasks.md) の `現在の作業項目` で確定する。
3. 領域内の補助状態/履歴が必要な場合は [tasks.md](tasks.md#repo-global-ガバナンス文書整合タスク) を参照する。
4. 作業内容は `work-items/` 配下を参照する。
5. 確認・レビュー証跡は `review-artifacts/` 配下を参照する。
