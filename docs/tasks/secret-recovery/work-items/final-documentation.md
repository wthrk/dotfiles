# #18 最終ドキュメント整理

- 作業種別: `恒久文書整理`
- 作業目的: 実装と検証を終えた secret-recovery 文書群を、仕様、設計、タスク、証跡、粗粒度進捗の責務に沿って整理し、重複、古い進捗メモ、壊れた導線を除去する。
- 構造完了条件:
  - 仕様、設計、台帳、証跡、粗粒度進捗の置き場が分離されている。
  - 同じ判断基準を複数ファイルで重複定義しない。
  - 利用者が入口から必要文書へ辿れる。
- 既存実装の流用方針: `既存文書は正本を尊重して再配置してよいが、古い進捗メモや重複本文は残さない。`
- 規約違反の解消対象:
  - 仕様、設計、台帳、証跡の責務混在
  - 古い進捗メモの残置
  - 重複した規則本文と壊れた参照
- レビュー合格条件: `恒久文書と進捗文書の責務分離が完了し、導線と参照が整合していること。`
