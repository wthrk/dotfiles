# #17 新規マシン復旧フロー統合

- 作業種別: `統合フロー実装と検証`
- 作業目的: YubiKey、Bitwarden Secrets Manager、GPG / SSH、password-store、Bitwarden Password Manager CLI を、新規マシン復旧の一連フローとして接続し、途中停止条件と検証経路を明確にした統合挙動へまとめる。
- 構造完了条件:
  - 個別 use case の結線は `application` 層で完結する。
  - 統合フローは各外部依存境界を跨いでも責務混在を起こさない。
  - 失敗時停止条件と再開条件が復旧フローとして一貫する。
- 既存実装の流用方針: `個別機能の完成差分を基礎に使うが、統合時に境界規約へ反する結線は残さない。`
- 規約違反の解消対象:
  - 個別機能の直接結合
  - application を介さない横断依存
  - 統合フローでだけ発生する入出力境界の漏れ
- レビュー合格条件: `新規マシン復旧フロー全体が application 主導で統合され、個別実装の境界違反を持ち込まないこと。`
