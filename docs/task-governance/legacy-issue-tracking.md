# 粗粒度 issue / phase 進捗

この文書は、個別タスクより大きい issue / phase / PR milestone の進捗をどう保持し、失われた情報をどう復元するかを定義する。

## 目的

粗粒度進捗は、現在の作業台帳とは別に、上位 issue、段階的 milestone、完了面を保持するために使う。個別タスクの台帳へ混ぜてはならない。

## 置き場所

- 粗粒度進捗は、対象領域配下の専用文書に置く。
- タスクファイルは、その専用文書への参照だけを持つ。

## 必須項目

- 親 issue / phase の識別子
- 子 issue / subtask の識別子
- 段階モデル
- 現在状態
- 復元根拠となる commit / log / issue / PR
- 情報欠落が残る場合の注記

## 復元規則

粗粒度進捗が失われている場合は、履歴復元担当が git 履歴、旧タスク文書、issue / PR タイトル、検証記録から復元する。復元した内容には、必ず出典を併記する。
