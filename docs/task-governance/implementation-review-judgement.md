# 実装レビュー判定

この文書は、レビュー開始条件とレビュー集約条件を定義する。

## 用途

- 対象差分のレビュー開始可否を判定する。
- 複数レビュー結果を集約して最終判定する。

## 必須レビュー担当

- 実装差分（executable behavior を含む変更）:
  - `構造レビュー担当`
  - `運用整合レビュー担当`
  - `セキュリティレビュー担当`
  - `仕様適合レビュー担当`
- 文書是正・文書主成果物:
  - `運用整合レビュー担当`
  - `参照整合レビュー担当`
- 追加で高リスク変更を含む場合は `セキュリティレビュー担当` を必須化する。

## レビュー開始条件

- 対象差分識別子がある。
- 最低1件の確認記録がある。
- 必須レビュー担当が割り当て済みである。
- 起動不能役割がある場合は、理由と代替実行者を記録する。

## 集約規則

- 1件でも `不合格` があれば未完了。
- `要修正` があれば修正後に再レビュー。
- 必須担当が全員 `合格` の場合のみ `集約後レビュー判定: 合格`。

## コミット連動規則

- コミット関連作業は `集約後レビュー判定` の記録後に開始できる。
- 個別メッセージやチャット上の宣言のみで完了扱いにしてはならない。
