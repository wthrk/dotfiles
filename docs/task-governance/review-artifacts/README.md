# review-artifacts

このディレクトリは、`task-list-outside` 判定の作業で使う記録の配置先である。

## 記録先

- 着手前判定（intake）: `outside-ledger-intake.md`
- 個別作業の確認/レビュー/検証（実施証跡）: `*.md`（1作業1ファイルを推奨）

## 非対象

- 領域台帳 (`docs/tasks/<area>/tasks.md`) に紐づく作業の証跡はこのディレクトリへ置かない。該当領域の `docs/tasks/<area>/review-artifacts/` を使う。
- `documentation-remediation` でも、領域台帳に紐づく作業はこのディレクトリの対象外とし、該当領域配下で記録する。
