# タスクファイル契約

この文書は、タスク台帳に必要な最小情報を定義する。

## タスクファイルの責務

- タスク台帳は「何を、どこまで、どの証跡で確認できるか」を保持する。
- 詳細手順や重複説明は持たない。

## タスクファイルに必須の項目（最小）

- `現在の作業項目`
- `各作業項目の状態`
- `各作業項目の主成果物`
- `対象コードパス` または `対象文書パス`
- `作業定義文書` 参照
- `レビュー記録` 参照

## 任意項目

次は必要な場合のみ記載する。

- 粗粒度進捗参照（`issue-*.md`）
- 詳細な担当識別子（`agent/run`）
- フォールバック詳細
- 固定実装単位トラッカー

## 作業定義文書に置く内容

- 目的、完了条件、境界条件、停止条件
- 作業項目固有の制約

## 重複禁止

- 同じ判定事実を複数文書へ必須重複させない。
- レビュー結果はレビュー記録を正本とする。
- 台帳はレビュー証跡への参照を保持すれば足りる。
