# docs

このディレクトリは、本リポジトリの文書群の入口である。

## 配下の項目

- [task-governance/README.md](task-governance/README.md): リポジトリ全体で共有するタスク運用規約の文書群を案内する。
- [tasks/README.md](tasks/README.md): 領域ごとのタスク台帳、作業定義、粗粒度進捗、証跡の配置先を案内する。
- [architecture/README.md](architecture/README.md): 実装アーキテクチャ規約の文書群を案内する。
- [secret-recovery/README.md](secret-recovery/README.md): 秘密情報復旧機能の仕様、設計、実装ガイドラインを案内する。
- [docs-governance.md](docs-governance.md): 文書配置、正本、重複禁止の規約を定義する。

## タスク管理の参照順

- 文書構成と正本の扱いは [docs-governance.md](docs-governance.md) を参照する。
- リポジトリ全体で共有する進め方は [task-governance/README.md](task-governance/README.md) を参照する。
- 領域ごとのタスクは [tasks/README.md](tasks/README.md) から辿る。
