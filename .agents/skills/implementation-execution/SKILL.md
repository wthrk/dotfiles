# Implementation Execution

## When To Use

Use this skill for implementation assignments.

## Required Reading

1. `docs/README.md`
2. `docs/task-governance/implementation-execution.md`
3. `docs/tasks/<area>/tasks.md`
4. `docs/tasks/<area>/work-items/<item>.md`

## Rules

- Follow required references, file-category reread obligations, and recording requirements from `docs/task-governance/implementation-execution.md`.

- Follow subagent assignment constraints from `docs/task-governance/workflow.md`.
